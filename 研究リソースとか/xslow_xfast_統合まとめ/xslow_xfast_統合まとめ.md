# X-slow / X-fast 統合まとめ（ENGB 無向 ＋ Congress）

図表・数値は `xslow_xfast_統合まとめ.pdf`、`merged_metrics.csv`、`fig_merged.png` を参照。

```
【1】系列の「型」は反応性の条件に応じて形を変えるが、内部 → 外部の順序は両ネットワークで保たれた
  RAM 上位 10 系列に含まれる 0 の平均個数 / 3 の平均個数（全 5 桁）
    ENGB     : baseline 3.1/0.8、X-slow 1.7/2.1、X-fast 3.1/0.3
    Congress : baseline 2.7/1.0、X-slow 1.1/2.8、X-fast 3.0/0.2
  X-slow : RAM 1位は ENGB 00333、Congress 03333。先頭付近に 0 を少数置き、
           その後ろに 3 を連続して置く。内部軸が速いので拡散の準備期間（0）が短くて済み、
           外部軸が鈍いので外部行動を促す 3 を何度も重ねる必要がある。
  X-fast : RAM 1位は両ネットワークとも 00002。0 を 4 回置いて、最後に 2 を 1 回だけ置く。
           内部軸が鈍いので拡散の準備に長くかかり、外部軸が速いので最後の 1 回で変換が済む。
  → 6 条件（2 ネットワーク × 3 条件）すべてで、RAM 上位 10 系列は全件が末尾 2 か 3 で終わり、
    最後の 0 より後ろに 2 か 3 がある。「前半に拡散促進型（0）、後半に外部行動促進型（2・3）」の順序は崩れていない。
    変わるのは 0 と 3 の配分（準備に何ラウンド使い、収穫に何ラウンド使うか）である。

【2】config の予測との照合（順序で得られる上積み = RAM 1位 ÷ URS、baseline を 1 とした比）
  RAM 1位 ÷ URS    ENGB     : baseline 3.36、X-slow 2.48（0.74 倍）、X-fast 1.52（0.45 倍）
                     Congress : baseline 2.21、X-slow 2.22（1.00 倍）、X-fast 1.44（0.65 倍）
  X-fast の予測「順序効果が縮小する」: 両ネットワークで成り立つ。ただし「消失」まではしておらず、1 倍は超えている。
  X-slow の予測「順序効果が拡大する」: 成り立たない。ENGB では baseline より小さく、Congress では baseline とほぼ同じである。
    （X-slow は絶対値が大きく伸びる。ENGB で URS が baseline の約 12 倍、Congress で約 1.5 倍。
     だが、系列を選ぶことによる相対的な上積みは増えていない）

【3】RAM（事前知識なしの固定系列）は、極端な条件でも OPT に近い
  RAM 1位 ÷ OPT 平均値: ENGB X-slow 0.921 / X-fast 0.864、Congress X-slow 0.980 / X-fast 0.968
  （baseline は ENGB 0.924、Congress 0.960）
  反応性を極端に振っても、RAM の価値は OPT の 0.86〜0.98 に収まっている。

【4】外部 / 内部比率は「内部行動が起きているか」の指標として読む
  X-fast の比率（全系列）: ENGB 9.37、Congress 7.32。share は ENGB 1.72、Congress 5.95 しかない。
  比率が大きいのは外部行動が多いからではなく、分母の内部行動がほとんど起きていないからである。
  X-slow の比率: ENGB 0.050、Congress 0.075。内部行動が大量に起きる一方、外部行動は相対的に少ない。

【5】解釈上の注意（この結果で言えないこと）
  ・ENGB は無向（directed=false）、Congress は有向（directed=true）で実行している。
    ネットワーク間の差は、構造の違いと向きの扱いの違いが混ざっており、分離できていない。
  ・ENGB の向きが結果を大きく左右する。以前の ENGB 実行（directed=true）では X-slow の URS が約 5 だったが、
    無向では 454 になった。同じパラメータでも向きの設定だけで約 91 倍動くため、
    ENGB の過去の数値と今回の数値は比較できない。
  ・どちらもモデル上の環境での結果であり、現実の SNS での再現性までは言えない。
  ・対象は 2 ネットワークのみ。順序パターンが保たれるという主張は、この 2 つで確認できた範囲に限る。
  ・個人単位のデータが無いため、拡散がどのノード層まで届いたかは直接確認していない。
```
