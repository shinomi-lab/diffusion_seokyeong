## 1. 研究の全体像

**題目**: SNS ユーザーの外部行動を最大化させる情報拡散戦略に関する一考察（匿名／指導 匿名）

**問い**: 複数回の投稿が可能なとき、「拡散を促す投稿」と「行動を促す投稿」を**どう組み合わせ、どの順序で**出せば、
外部行動（購買・来場などのコンバージョン）が最大になるか。先行研究 [5]（Miyashita ら, IEICE E106-D）のメッセージ 3 種を 4 種へ拡張して調べる。

**モデル**（先行研究を引き継ぐ）:
- 有向グラフ上の独立カスケード（IC）。各ユーザに意思決定 `u' = w·u + (1−w)·s(m)`（`u>0` で行動）。
- **内部活性化**（`u^S>0`、シェア）は送信者集合に加わり**拡散を前へ進める唯一の機構**。毎回再判定され ON/OFF を往復する。
- **外部活性化**（`u^X>0`、取引）は**記録されるだけで伝播に寄与しない**。生涯 1 回限り。
- ∴ 外部活性化しうる母数を増やす唯一の手段は、先行ラウンドで内部活性化ノードを増やすこと。
- 反応性 µ（w の逆算元）はパレート分布からサンプリング（敏感な少数・鈍感な多数）。`β` が速さ（`n_max=β·T`）、
  `γ` は β と組で裾の重さ（`α=γ/(β−γ)`）を決める。
- IP が打つのは長さ T の**メッセージ系列**。OPT（シナリオごとの最良）／RAM（全体平均で最良の単一系列）／URS（一様ランダム）で評価。

**メッセージ空間（4 種、内部＋外部＝0.25 一定の構造的トレードオフ）**:
m0=(0.20, 0.05) m1=(0.15, 0.10) m2=(0.10, 0.15) m3=(0.05, 0.20) ※(内部, 外部)。**番号 0 が拡散寄り、3 が外部寄り**
（先行研究の 3 種は m0 が外部寄りで**向きが逆**。系列表記はすべて本研究の向き、**先頭＝ラウンド 1**）。
T=5、L=4 → 4⁵=**1024 系列**。拡散試行 100、IP 16、ユーザ状態 32（先行時 48）。

**対象ネットワーク**: Twitter 81,306 / Twitch-DE 9,498 / ENGB 7,126 / FR 6,549 / ES 4,648 ノード。
中心性（VC・PageRank 他）の順位相関も計算し、VC–PageRank ρ≈0.99（予測妥当性は未検証）。

**baseline の主結果**:
- 有効な系列は**「前半に拡散促進型(0)を多め → 最終ラウンドに外部行動促進型(3)」**。OPT・RAM の共通主系列は `00003`
  （ENGB のみ `00033`）。共通するのはパターンのほう。
- RAM 単一系列で対 OPT 約 93%（Twitter）。適用で外部行動者数 ×1.4〜×3.8、外部/内部比率 +17.0〜+33.7pt。
  内部行動（拡散量）そのものの増加は ENGB で横ばい。普遍的に言えるのは外部行動の増加と比率向上まで。
- 退化系列: `00000`（外部 0）、`33333`（低活性ケースで argmax になるだけ）は有効な系列として扱わない。
- 既知の修正: 旧実装は `msg` の記録順が逆だった（読む順が逆だっただけで結果に影響なし、対応済み）。

### 1.1 推薦チャネルに取り組む意図と今後の目的（2026-10-26〜）

**意図**: 実在の SNS（X の For You、Instagram の Explore・Reels など）では、投稿はフォロー関係だけでなく
**推薦アルゴリズムによってフォロー外へも届く**。本研究の結論（「拡散 → 頭打ち」型の系列が最適）は推薦の無い
IC モデルの上で得たものなので、**推薦がある環境でも最適な系列・IP の選び方が保たれるのか、どう変わるのか**を調べる。
- 推薦は**シェア（内部行動）だけを見る**（外部行動は SNS の外で起きるので、プラットフォームには見えない）。
  したがって推薦は System 1 の反応（内部行動）を増幅する仕組みとして入る。
- 本研究の結果では、外部行動を増やすにはまず多くのノードへ届けて刺激を当てる必要がある（バイラルが手段）。
  そのため、シェアを最大化する推薦の目的は、外部行動の最大化と**手段として整合する**。ずれが残るのは、
  外部促進のメッセージ（m3）を出す転換のラウンドだけで、そこでは推薦が付きにくい（仮説 H1・H2）。

**位置づけ**: 推薦を**まず単純な形で導入する**段階。実SNSの推薦に共通する骨格（候補を集める → 反応を予測して
点数をつける → 上位を見せる）を、「反応が良いメッセージほどフォロー外へ多く届く」1 つの規則に縮めた（Rモデル）。
個人化（利用者ごとの関心）と、複数アイテムの順位づけは意図して持たない。推薦の強さ ε = 0 で従来モデルと完全に一致する
（入れ子）ので、これまでの結果は「ε = 0 の点」としてそのまま使える。

**今後の目的 — 競合モデル開発への準備**: 次の段階では、**他者 IP との競合**（複数の発信者・複数のアイテムが
利用者の限られた注意と表示枠を奪い合う）を入れたモデルを作る。今回の単純な推薦はその土台であり、競合モデルで
- 複数アイテムの**順位づけ**と表示枠（位置による注意の配分）、
- **個人化**（点数の行列の階数を上げる。例: コミュニティのラベル）、
- フォロー外の投稿の点数の割引 δ を、表示枠の奪い合いでの**露出の割引**として独立に効かせること
（単一アイテムの今のモデルでは ε との積しか効かない）
を扱う。今回の段階で、推薦の数理モデル（`../../reccomend_system/推薦システム単純.md`）、Rust 実装（core 0.3.0）、
ビューアでの可視化（`recommender-v3-design.md`）をそろえ、競合モデルを同じ枠組みで足せるようにした。

## 3. 検証フェーズの結論（パラメータを動かしても順序効果は保たれるか）

問い: 「拡散多め → 外部寄り」という順序は、メッセージ内容（δ_X）や、ユーザの反応性（β,γ）を動かしても成り立つか。

**(a) δ_X を動かす**（外部軸の差別化度。`s̄` は固定で w の較正は不変、Twitter、`結果.pdf` の baseline と比較）:

| 指標 | baseline (0.6) | extzero (1.0) | extneg (1.4) |
|---|---|---|---|
| RAM 1位 | `00003` | `00013` | `00013` |
| `00003` の RAM 順位 | 1 | 2 | 4 |
| 末尾 m3（RAM 上位 10 / OPT 上位 10）| 7/10・8/10 | 9/10・9/10 | 10/10・10/10 |
| RAM 単一 / OPT | 93.4% | 90.1% | 88.6% |
| 外部行動者数の倍率 | ×3.77 | ×4.46 | ×4.82 |

→ 主系列は `00003` から `00013` へ移るが、「前半 0・末尾に外部寄り」の型は**強まる**。C1〜C7 の判定は `*_結果.pdf` の照合表。

**(b) 反応性 β/γ を動かす**（軸非対称。X-slow＝内部が速く外部が鈍い、X-fast＝その逆。α=3 共通で動かすのは速さのみ）:
- 6 条件（ENGB・Congress × baseline/X-slow/X-fast）すべてで、RAM 上位 10 は**全件が末尾 2 か 3**、最後の 0 より後ろに 2・3 がある。
  **内部 → 外部の順序は崩れない**。変わるのは 0 と 3 の配分: X-slow は `00333`（ENGB）/`03333`（Congress）、X-fast は両方 `00002`。
- config の予測との照合（順序で得られる上積み = RAM 1位 ÷ URS、baseline との比）:
  X-fast「順序効果が縮小」は両ネットワークで成立（ただし消失はせず 1 倍超）。
  **X-slow「順序効果が拡大」は成立しない**（ENGB は baseline より小さく、Congress はほぼ同じ）。
- RAM 1位 ÷ OPT 平均値は 0.86〜0.98。反応性を極端に振っても RAM は OPT に近い。
- xact/share 比は「外部が多いか」ではなく**内部行動が起きているか**の指標（X-fast は share がほとんど起きず比が 7〜9 になる）。

**暫定結論**: 系列の順序（内部 → 外部）は、δ_X と反応性の両方を動かしても保たれる。パラメータが動かすのは 0 と 3 の**配分**
（準備に何ラウンド使い、収穫に何ラウンド使うか）である。※暫定。ユーザー自身の結論文（Notion 掲載分）はこのファイルに無い。

**言えないこと**: 対象は 2 ネットワークのみ／ENGB は無向・Congress は有向で、構造差と向きの差が混ざる
（ENGB は向きだけで X-slow の URS が約 91 倍変わるため、過去の有向 ENGB の数値とは比較不可）／個人単位データが無く、
拡散がどの層まで届いたかは直接見ていない／モデル内の結果で現実の SNS での再現性までは言えない。

- 中心性の予測妥当性（VC・PageRank で選んだ発信者が実際に外部行動者数を増やすか）は未検証。
- 推薦チャネル: 実データ（ENGB・Twitter など）での実験（典型系列 × ε・θ・τ、相図、IP 選択）と、既定値（ε など）の決定。
  推薦の効果は大きく出やすい（Twitter 規模でラウンドあたり数万人に届く）ので、臨界の近くかどうかを確かめて読む。
- 競合モデル（他者 IP との競合、順位づけ・個人化・露出の割引 δ）の設計（§1.1）。
