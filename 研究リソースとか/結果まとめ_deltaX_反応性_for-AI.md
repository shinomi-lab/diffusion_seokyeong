# δ_X 調整・反応性（β,γ）調整の結果まとめ（他の AI に渡す用）

この文書だけで、研究の前提・用語・実験条件・結果・結論・限界が分かるように書いてある。
数値は `研究リソースとか/` 内の CSV・PDF から転記した実測値。推測で足した数値はない（派生値は「算出」と明記）。

---

## 1. 研究の前提（最小限）

- **何をしているか**: SNS 上の情報拡散シミュレーション。情報提供者（IP）が T ラウンドにわたり、4 種のメッセージ（m0〜m3）から
  1 つずつ選んで投稿する。**どの順序で投稿すれば外部行動（購買・来場などのコンバージョン）が最大になるか**を、
  全 4^T 通りの系列を総当たりして調べる（T=5 → 1024 系列）。
- **ユーザの 2 種類の行動**（各ユーザが受信のたびに独立に判定）:
  - **内部行動 S（シェア）**: 効用 `u^S>0` で成立。成立したノードは**メッセージを隣接ノードへ確率 p で渡す**。
    毎回再判定され、ON/OFF を往復する。**拡散を前へ進める唯一の機構**。
  - **外部行動 X（取引）**: 効用 `u^X>0` で成立。**記録されるだけで伝播に一切寄与しない**。生涯 1 回限り。
  - 効用更新: `u' = w·u + (1−w)·s(m)`（`w` は過去の保持重み、`s(m)` はメッセージの刺激）。
- **メッセージ**: 各メッセージは (内部刺激, 外部刺激) の組。baseline は
  m0=(0.20, 0.05) / m1=(0.15, 0.10) / m2=(0.10, 0.15) / m3=(0.05, 0.20)。
  **番号 0 が拡散寄り、3 が外部行動寄り**（内部＋外部＝0.25 一定のトレードオフ）。
- **系列表記**: `00003` は「ラウンド 1〜4 に m0、ラウンド 5 に m3」。**先頭がラウンド 1**。
- **出力の単位**: 1 行＝(シナリオ, 系列)。`mean_num_xact`（外部行動者数）・`mean_num_share`（内部行動回数）は
  **T ラウンド合計**のモンテカルロ平均（100 試行）。ラウンド別の内訳は存在しない。個人単位のデータも無い。
  シナリオ = (IP ノード 16 種) × (ユーザ状態サンプル 32 種) = 512。
- **評価指標**:
  - **OPT**: シナリオごとに最良の系列を選べる場合（理論上限。評価値＝各シナリオ最良値の平均）。
  - **RAM**: シナリオを知らずに、全シナリオ平均が最大の**単一系列**を固定で使う場合（現実的な戦略）。上位 10 系列を RAM 集合とする。
  - **URS**: 各ラウンドで一様ランダムに選ぶ（全 1024 系列の平均）。
  - 退化系列: `00000`（拡散のみ、外部 0）、`33333`（外部促進のみ、低活性ケースで argmax になるだけ）は有効な系列として扱わない。

### baseline の既知の結果（5 ネットワーク共通）

- 有効な系列は「**前半に拡散促進型(0)を多め → 最終ラウンドに外部行動促進型(3)**」。OPT・RAM の共通主系列は `00003`（ENGB のみ `00033`）。
- RAM 単一系列で対 OPT 約 93%（Twitter）。

## 2. パラメータの意味（調整した 2 つの軸）

### δ_X（外部軸の差別化度）

外部刺激を `s_X(i) = s̄_X · (1 + δ_X · z_i)`、`z = (1, 1/3, −1/3, −1)`（m0〜m3 の並び位置）と分解したときの係数。
**平均 `s̄_X` を変えずに、メッセージ間の外部刺激の散らばり（効き方の差）だけを広げる**操作。
`s̄_X = 0.125` 固定なので重み `w` の較正は変わらず、差別化の効果だけを取り出せる（内部軸側は δ_S で同じ構造。baseline は δ_S = δ_X = 0.6）。

| δ_X | 外部刺激 (m0 / m1 / m2 / m3) | 意味 |
|---|---|---|
| 0.6（baseline）| 0.05 / 0.10 / 0.15 / 0.20 | 全メッセージが外部行動を促す向き |
| 1.0（extzero）| 0 / 0.0833 / 0.1667 / 0.25 | m0 は外部行動に対して**中立**（刺激ちょうど 0）|
| 1.4（extneg）| −0.05 / 0.0667 / 0.1833 / 0.30 | m0 は外部行動を**抑える**（負の刺激）|

### 反応性 β, γ（ユーザの動きやすさの分布）

各ユーザの反応性 µ をパレート分布 `Pareto(scale = 1/(β·T), shape = γ/(β−γ))` から引き、`w = (s̄/(s̄−u0))^µ` で重みを逆算する。
必要ラウンド数 `n = 1/µ` について以下が成り立つ（解析的に導出し、20 万サンプルで数値確認済み）:

- **速さ**: 最大必要ラウンド `n_max = β·T`。β だけが速さを決める（β 小 → 速い）。
- **裾の重さ**: `α = γ/(β−γ)`。分布は `P(n ≤ x) = (x/n_max)^α`。
- 制約 `γ < β`。設計は (n_max, α) を先に決めて β,γ に変換する。
- 内部決定（シェア）と外部決定（取引）で**別々に**指定できる（軸非対称が作れる）。`initial_utility = −1.0`（全ユーザ最初は動かない）。

| 呼称 | β | γ | n_max（T=5）| α | T=5 までに発火しない割合 |
|---|---|---|---|---|---|
| FAST | 0.4 | 0.30 | 2.0 | 3 | 0%（全員 2 ラウンド以内）|
| baseline | 0.8 | 0.60 | 4.0 | 3 | 0% |
| SLOW | 1.4 | 1.05 | 7.0 | 3 | 約 64%（算出: 1−(5/7)³）|

FAST/baseline/SLOW は **α=3 で共通**。この実験で動かしたのは**速さ（n_max）だけ**で、裾の重さは動かしていない。

## 3. 実験 1: δ_X 調整

- 条件: δ_X = 0.6 / 1.0 / 1.4。他は baseline と同一（β=0.8, γ=0.6 等）。
- ネットワーク: **Twitter（81,306 ノード、有向）**。baseline 値は既発表の記録値（全 1024 系列の分布は手元に無い）。

| 指標 | baseline (0.6) | extzero (1.0) | extneg (1.4) |
|---|---|---|---|
| RAM 1位の系列 | `00003` | `00013` | `00013` |
| `00003` の RAM 順位 | 1 | 2 | 4 |
| RAM 1位の xact | 1000.26 | 1098.56 | 1241.75 |
| OPT 評価値 | 1071.12 | 1219.08 | 1400.79 |
| RAM 単一 / OPT | 93.4% | 90.1% | 88.6% |
| RAM 上位 10 平均 / OPT | 79.6% | 78.8% | 78.4% |
| xact 全系列平均（URS）| 226.41 | 215.14 | 227.75 |
| RAM 1位 ÷ URS（算出）| 4.42 | 5.11 | 5.45 |
| 最大化 msg 適用後の外部行動者数の倍率 | ×3.77 | ×4.46 | ×4.82 |
| 外部/内部 比率の向上 | +25.8pt | +57.8pt | +87.7pt |
| OPT・RAM の共通系列数 | 1 | 6 | 7 |
| 末尾 m3（RAM 上位 10）| 7/10 | 9/10 | 10/10 |
| 末尾 m3（OPT 上位 10）| 8/10 | 9/10 | 10/10 |

- RAM 上位 10（extzero）: `00013, 00003, 00023, 00033, 10003, 10013, 10023, 00103, 00113, 00022`。
- RAM 上位 10（extneg）: `00013, 00023, 00033, 00003, 10023, 10013, 10003, 10033, 00113, 00123`。
- share（内部行動）の全系列平均は 3 条件とも 357.86 で同一（外部刺激を変えても拡散量は変わらない）。
- extzero と extneg の系列別 xact の相関（全 1024 系列）: 0.9886。
- 既発表の主張 C1〜C7（型・共通系列・対 OPT・倍率・比率）は両条件で成立（C3/C4 は baseline の 93%/80% からやや低下）。

**読み取り**: 外部刺激の差別化を強めると、主系列は `00003` から `00013`/`00023`/`00033`（後ろ寄りに外部促進を増やす型）へ移るが、
「前半は拡散寄り、末尾は外部寄り」という型はむしろ**強まる**（末尾 m3 が 7→9→10/10）。順序は崩れない。

## 4. 実験 2: 反応性（β,γ）調整 — X-slow / X-fast

- 条件（message_space と他は baseline 固定。内部と外部の反応性だけを入れ替える）:

| 条件 | 内部軸（シェア）| 外部軸（取引）| 狙い・事前予測 |
|---|---|---|---|
| **X-slow** | FAST（β=0.4, γ=0.30）| SLOW（β=1.4, γ=1.05）| 拡散は即座に完成し、外部行動の蓄積だけが必要 → 順序効果が**拡大**するはず |
| **X-fast** | SLOW | FAST | いつ m3 を打っても即変換でき、拡散構築が追いつかない → 順序効果が**縮小・消失**するはず |
| baseline | β=0.8, γ=0.6 | 同左 | 参照（対称）|

- ネットワーク: **Twitch-ENGB（7,126 ノード、無向 `directed=false`）** と **Congress（475 ノード、有向）**。
  別 PC で実行。ENGB の baseline も同じ無向で再実行した値（過去の有向 ENGB 実行値とは比較できない）。

### 結果（RAM / OPT / URS と統合指標）

| 指標 | ENGB baseline | ENGB X-slow | ENGB X-fast | Congress baseline | Congress X-slow | Congress X-fast |
|---|---|---|---|---|---|---|
| URS（全系列平均 xact）| 37.66 | 454.04 | 16.09 | 75.62 | 114.01 | 43.55 |
| RAM 1位の系列 | `00003` | `00333` | `00002` | `00023` | `03333` | `00002` |
| RAM 1位の xact | 126.47 | 1123.84 | 24.49 | 166.86 | 252.71 | 62.57 |
| **RAM 1位 ÷ URS** | 3.36 | 2.48 | 1.52 | 2.21 | 2.22 | 1.44 |
| RAM 上位 10 平均 xact | 108.23 | 1050.57 | 23.12 | 156.16 | 235.40 | 58.67 |
| 適用倍率（上位 10 ÷ 全系列）| 2.87 | 2.31 | 1.44 | 2.07 | 2.06 | 1.35 |
| **RAM 1位 ÷ OPT 平均値** | 0.924 | 0.921 | 0.864 | 0.960 | 0.980 | 0.968 |
| share（全系列平均）| 59.05 | 9012.65 | 1.72 | 124.83 | 1512.45 | 5.95 |
| xact/share（全系列）| 0.638 | 0.050 | 9.37 | 0.606 | 0.075 | 7.32 |
| RAM 上位 10 の 0 の平均個数 | 3.1 | 1.7 | 3.1 | 2.7 | 1.1 | 3.0 |
| RAM 上位 10 の 3 の平均個数 | 0.8 | 2.1 | 0.3 | 1.0 | 2.8 | 0.2 |
| OPT 最頻（退化除く）| `00003` | `02333` | `00002` | `00033` | `03333` | `00002` |

- ENGB X-slow の RAM 上位 10: `00333, 00233, 01333, 00133, 01233, 00323, 01133, 00223, 00033, 02233`（全件が末尾 3）。
- ENGB X-fast の RAM 上位 10: `00002, 10002, 00003, 00012, 01002, 10003, 00013, 00102, 00022, 10012`（全件が末尾 2 か 3）。
- 6 条件（2 ネットワーク×3）すべてで、RAM 上位 10 は**全件が末尾 2 か 3**、かつ最後の 0 より後ろに 2・3 がある。

### 読み取り

1. **順序は崩れない**: 「前半に拡散促進型(0)、後半に外部行動促進型(2・3)」の型は 6 条件すべてで保たれた。
   変わったのは 0 と 3 の**配分**だけ。
   - X-slow: 内部が速いので拡散準備（0）は短くて済み、外部が鈍いので 3 を連続して重ねる（`00333`, `03333`）。
   - X-fast: 内部が鈍く拡散準備に長くかかり、外部が速いので最後の 1 回で変換が済む（`00002`）。
2. **事前予測との照合**:
   - X-fast「順序効果が縮小」: **成立**。RAM 1位÷URS が baseline の 0.45 倍（ENGB）/0.65 倍（Congress）。
     ただし**消失はしていない**（1.52, 1.44 と 1 倍超）。
   - X-slow「順序効果が拡大」: **成立しなかった**。ENGB は baseline より小さく（0.74 倍）、Congress はほぼ同じ（1.00 倍）。
     X-slow は絶対値は大きく伸びる（ENGB で URS が baseline の約 12 倍、Congress で約 1.5 倍）が、系列を選ぶことによる相対的な上積みは増えていない。
3. **RAM は極端な反応性でも OPT に近い**: RAM 1位÷OPT 平均値は 0.86〜0.98。
4. **xact/share 比は「外部が多いか」ではなく「内部行動が起きているか」の指標**: X-fast は share がほとんど起きず（ENGB 1.72、Congress 5.95）、
   分母が小さいので比が 7〜9 と大きくなる。X-slow は内部行動が大量に起き、外部が相対的に少ないので比が 0.05〜0.08。
5. X-fast で順序効果が弱まる原因は、各ユーザの内部活性化の反応性を弱めたことで、全体的に拡散構築ができなかったこと。

---

## 5. 結論（両実験を通して）

1. **系列順序「先に内部（拡散）活性化 → 後に独立した外部行動活性化」は、δ_X 調整・反応性調整のどちらでも、
   ネットワークに依存せず保たれ、効果も維持された**（検証範囲: Twitter / ENGB / Congress）。動いたのは 0（拡散準備）と 3（外部促進）の配分だけ。
2. **本モデルでの外部行動最大化の戦略は、隅々のノードまで先に内部行動活性化させ、IP からの入力を伝播させること以外に考えにくい。**
   外部活性化は伝播に寄与せず記録されるだけなので、外部活性化しうる母数を増やす手段は内部活性化の拡大しかない。
   だから末尾に外部促進を置き、それまでの拡散で母数を作るという順序が、パラメータを動かしても残る。

## 6. 限界・読むときの注意

- **2 つの結論は本モデルの範囲内の結果**で、現実の SNS での再現性までは言えない。結論 2 は「他の戦略が無い」の証明ではなく、検証した範囲で他の型が現れなかったという考察。
- **検証したネットワークは限られる**: δ_X は Twitter 1 つ、β/γ は ENGB と Congress の 2 つ。
- **ENGB（無向）と Congress（有向）は向きの扱いが違い、構造差と向きの差が混ざる**。ENGB は向きだけで結果が桁違いに変わる
  （X-slow の URS: 有向の過去実行で約 5、無向で 454。約 91 倍）ので、有向と無向の数値は比較しない。
- **δ_X の baseline 値は記録値のみ**（全 1024 系列を持たない）。baseline と extzero/extneg の比較は記録のある指標に限る。
- **個人単位のデータが無い**ため、拡散がどのノード層まで届いたかは直接確認していない（メカニズムの説明は集計値からの推論）。
- **メッセージ空間はトレードオフ構造（内部＋外部＝一定）の範囲**で、m が 4 種・T=5 に限られる。刺激の構成を変える（相反しない組・同一値）、
  ラウンドを増やす、外部効用の上限到達ノードを数える、といった拡張は未検証。
- 研究メモ（Notion）に「X-fast の順序効果は消失した」と書かれた箇所があるが、**数値は「縮小」まで**（上記 2.）。
